Shape of a line

{{ p }}command argument "an argument with spaces" | other {1} && third > channel.saved
  • The command sign starts a line. After an emoji sign a space is allowed: {{ p }} ping.
  • Arguments are split on spaces. Use "quotes" to keep spaces, and \ to escape a character literally (\", \{).
  • Only the final result is sent to chat.

Operators

These count as operators only when they stand alone between spaces, so ordinary chat like (lol) or -> is never mistaken for one.

Placeholders

{reference}, {reference:type}, {reference ?? fallback}. A reference that isn't available in the current context is an error before anything runs, and a missing value without a ?? fallback stops the command.
